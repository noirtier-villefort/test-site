# Моя смена — Telegram Mini App

Мини-приложение для подсчёта заработка во время смены. Использует HTML, CSS, Vanilla JavaScript и официальный Telegram Web Apps SDK. Сборка, npm и backend не нужны.

## Возможности

- Настройка почасовой ставки, плановой длительности смены и валюты.
- Начало, пауза, продолжение и завершение смены.
- Паузы исключаются из оплачиваемого времени.
- Сверхурочные продолжают начисляться после запланированного времени.
- Сумма вычисляется по временным меткам, а не накоплением тиков таймера.
- Восстановление текущей смены после перезагрузки.
- Локальная история последних 100 смен.
- Адаптивный интерфейс и поддержка светлой/тёмной темы.
- В Telegram используются нативные подтверждения там, где они доступны.

## Запуск локально

Для тестирования в обычном браузере нужен локальный HTTP-сервер. Из папки проекта выполни одну из команд:

### Python

```bash
python3 -m http.server 8000
```

Затем открой http://localhost:8000.

### Node.js

Если установлен Node.js, можно использовать `npx serve .`, но это необязательно.

Для локального теста Telegram SDK может быть загружен, но Mini App API будет полноценно работать только внутри Telegram.

## Публикация через HTTPS

Подойдёт любой статический хостинг с HTTPS, например GitHub Pages, Cloudflare Pages или Vercel.

### Вариант: GitHub Pages

1. Создай репозиторий на GitHub и загрузи четыре файла в корень репозитория.
2. Открой **Settings → Pages**.
3. В разделе сборки выбери публикацию из ветки, например `main`, папка `/ (root)`.
4. Сохрани настройки и дождись публикации сайта.
5. Скопируй выданный HTTPS URL. Он должен открывать `index.html`.

### Подключение к Telegram через BotFather

1. Открой [@BotFather](https://t.me/BotFather) и выполни `/newbot`, если у тебя ещё нет бота.
2. Следуй инструкциям BotFather и сохрани токен бота в безопасном месте. Этот фронтенд токену не нуждается — не добавляй его в HTML или JavaScript.
3. В BotFather настрой Mini App для своего бота. Названия пунктов могут меняться; используй актуальные команды и меню BotFather для настройки Main Mini App или Web App.
4. Укажи опубликованный HTTPS URL.
5. Открой бота в Telegram и запусти приложение через настроенную кнопку/пункт меню.

Документация: https://core.telegram.org/bots/webapps

## Как работает расчёт

Оплачиваемое время:

- во время смены: накопленное время до последнего продолжения плюс время с последнего продолжения;
- на паузе: только накопленное оплачиваемое время;
- заработок = ставка × оплачиваемые миллисекунды / 3 600 000.

Плановая длительность используется для прогресс-бара и прогноза. Она **не ограничивает начисление**: после достижения плана продолжают учитываться сверхурочные.

## Хранение данных и ограничения

- Настройки, активная смена и история хранятся в `localStorage` текущего браузерного контекста.
- История не синхронизируется между устройствами и может быть потеряна при очистке данных браузера/Telegram.
- Это локальный счётчик, а не официальный расчёт зарплаты. Он не учитывает налоги, округление работодателя, разные ставки сверхурочных или неоплачиваемые правила, кроме явно поставленных на паузу периодов.
- Если приложение было закрыто во время работающей смены, время продолжает считаться по временным меткам. Если смена была на паузе, время паузы не учитывается.
- В продакшене не доверяй клиентским данным для финансовых расчётов или подтверждения личности. Для этого понадобится серверная проверка `Telegram.WebApp.initData`.

## Быстрый тест

1. Установи ставку `36`, длительность `8`, валюту `PLN`.
2. Нажми **Начать смену** — сумма начнёт расти.
3. Нажми **Пауза** на несколько секунд — сумма должна остановиться.
4. Нажми **Продолжить смену** — начисление возобновится.
5. Обнови страницу — активная смена должна восстановиться.
6. Заверши смену и проверь, что она появилась в истории.
7. Чтобы проверить сверхурочные без ожидания, временно укажи короткую плановую длительность, например `0,25` часа.
